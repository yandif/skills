# {{PKG}}

Panda CSS preset replicating the design language of **{{SOURCE}}**.
Generated by the `site-to-panda-preset` skill from computed styles, CSS variables and screenshots.

## Use it

```ts
// panda.config.ts
import { defineConfig } from '@pandacss/dev'
import preset from '{{PKG}}'   // or a relative path to ./preset

export default defineConfig({
  presets: ['@pandacss/preset-base', preset],   // preset-base = utilities; this preset = the theme
  include: ['./src/**/*.{ts,tsx}'],
  outdir: 'styled-system',
})
```

Dark mode is driven by the `dark` condition in `preset/conditions.ts`.

## Layout

| file | what lives there |
| --- | --- |
| `preset/tokens.ts` | raw palette and scales (colours, fonts, sizes, spacing, radii, shadows, motion) |
| `preset/semantic-tokens.ts` | role-based colours with light/dark values |
| `preset/text-styles.ts` | named type styles |
| `preset/layer-styles.ts` | surface bundles |
| `preset/recipes.ts` | component recipes |
| `preset/global-css.ts` | page defaults |
| `preset/conditions.ts` | dark-mode switch |
