# 模板

## 提交信息

```
<type>: <一句话说明做了什么>

做了什么：
- ...

怎么验证：
- 运行 <命令>，预期 <结果>
- 手动检查 <页面/操作>

怎么回滚：
- git revert <hash>
- 若涉及数据/配置：<回滚步骤>
```

## 重启简报（同一问题修复 3 次失败后）

```
## 问题
<现象、复现步骤、影响范围>

## 期望
<正确行为应该是什么>

## 已尝试的方案
1. <方案> → <结果/为什么没用>
2. ...
3. ...

## 已获得的证据
<日志、真实数据、运行表现>

## 当前怀疑方向（如有）
<仅列有证据支持的>
```

## 回归测试用例登记

```
- 来源：<线上 Bug / 用户反馈 链接或描述>
- 现象：...
- 根因：...
- 用例位置：<测试文件路径>
- 运行方式：<命令>
```

## AGENTS.md / CLAUDE.md 条目建议格式

```
## 产品规范
- <用户确认过的规范，一条一行>

## 已否决方案
- <方案>：否决原因 <一句话>

## 项目特殊要求
- <代码里看不出来的约束>
```
